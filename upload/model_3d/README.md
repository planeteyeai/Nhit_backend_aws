# model_3d — LAS sources for Potree

Project folders under this path (on S3: `s3://nhitbucket/upload/model_3d/{project}/…`) hold **LAS/LAZ** point clouds.

They are converted to Potree 2.x under `s3://nhitbucket/upload/potree/{project}/…`.

There is **no GLB catalog** here (`models.json` / LFS GLB library removed).
